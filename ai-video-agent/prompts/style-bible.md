# Original Storybook Fantasy Style Bible

Use this direction for all image and video generation prompts.

## Visual Direction

Original hand-painted pastoral fantasy animation with soft watercolor skies, warm lantern light, expressive but simple character designs, old forests, cozy villages, drifting clouds, mossy ruins, gentle creatures, and cinematic storybook atmosphere.

Do not imitate a living artist. Avoid naming specific living artists in generation prompts. Use broad cinematic and animation language instead.

## Consistency Rules

- Keep one consistent main character across all scenes.
- Reuse the same color palette: moss green, warm amber, faded blue, cream, rain gray.
- Prefer slow camera motion: gentle pan, slow push-in, drifting parallax.
- Keep clips loopable where possible.
- Use image-to-video from approved reference frames for the best coherence.
- Avoid sudden style changes, modern objects, logos, text artifacts, and distorted faces.

## Base Prompt

Original hand-painted pastoral fantasy animation, soft watercolor background, warm lantern light, cozy village and ancient forest details, gentle cinematic camera movement, expressive character silhouette, atmospheric depth, clean composition, coherent storybook fantasy world, high quality, 16:9.

## Negative Prompt

photorealistic, horror, gore, celebrity likeness, living artist imitation, logos, subtitles in image, text artifacts, distorted hands, distorted faces, low resolution, flicker, inconsistent character design, modern cars, modern city objects.

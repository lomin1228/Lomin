# The Toolkit — the "perfect tools" for this dissertation

These are the tools I'll use *with* you. All free/open-source unless noted; nothing here requires money.

## 1. Reference management — **Zotero** (free)
- Browser connector saves journal articles + auto-grabs metadata; one-click **Harvard (Cite Them Right)** bibliography for Word.
- I maintain a parallel verified list in `05 references.md` and can export a `.bib` for LaTeX if you ever want it.
- Why: examiner-checkable references; no fabricated citations.

## 2. GIS / spatial analysis — **QGIS** (free, open source)
- For the spatial metrics in `03 methodology` §3c (area, accessibility, green %, provision counts) and the comparison maps.
- Data: OpenStreetMap, **OS Open Greenspace / OS Open Data** (London), **NYC Open Data POPS layer**, **HK GeoData / Lands Dept**, **London Datastore**.
- I can write the QGIS steps and the data-download list; you run it, I help interpret.

## 3. Quantitative scoring + charts — **Python** (pandas + matplotlib) *or* plain spreadsheet
- The index scores live in `data/publicness_scores.csv`; a small script in `analysis/` turns them into the **Németh–Schmidt quadrant scatter** and the **Varna–Tiesdell radar stars**.
- Easy to interpret, fully reproducible, regenerates instantly if scores change.
- A spreadsheet alternative works too if you prefer no code.

## 4. Qualitative coding — **NVivo** (UCL provides a licence) or manual
- For the document/discourse analysis of the OAPFs, master plans and design guides you already hold in `../sources/`.

## 5. Fieldwork capture — phone + a printed coding sheet

## 6. Writing & critique — me, via two skills
